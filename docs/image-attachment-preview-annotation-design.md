# 图片附件右侧预览与坐标标记方案

## 1. 范围

本方案只处理聊天提示词区域中、尚未发送的图片附件。

- 支持单击图片附件，或在右键菜单中选择“打开”。
- 图片在右侧“用户附件”区域预览。
- 非图片附件、历史消息中的附件、多图片预览 Tab 不在本方案范围内。

## 2. 图片预览

### 2.1 打开规则

1. 单击图片附件后，右侧切换到“用户附件”预览区域。
2. 右键图片附件后选择“打开”，行为与单击相同。
3. 右侧一次只显示一张图片。
4. 点击第二张图片时，第二张图片直接替换第一张图片。

图片附件不进入文本编辑器，因此不应出现“二进制文件，无法打开”的提示。

### 2.2 工具栏

右侧预览工具栏提供以下操作：

- 标记；
- 比例：原图、16:9、4:3、1:1；
- 缩放：适应窗口及不同放大比例。

比例和缩放只影响右侧预览效果，不修改原始图片文件。

## 3. 图片标记

### 3.1 交互

1. 用户点击“标记”，进入标记状态。
2. 用户点击图片中的目标位置。
3. 图片当前位置显示递增编号：1、2、3、4……。
4. 同时显示输入框，用户填写该位置的说明。
5. 每个标记记录标记序号、点击坐标和输入内容。

不使用浏览器网页元素识别，不需要框选，也不生成新的标记图片。

### 3.2 坐标计算

坐标必须以原图宽高为基准，记录为百分比，而不是窗口、屏幕或右侧面板坐标。

```text
x = (点击位置相对图片左侧的距离 / 图片实际显示宽度) × 100%
y = (点击位置相对图片顶部的距离 / 图片实际显示高度) × 100%
```

坐标保留一位小数。比例和缩放变化不影响已记录的坐标含义。

例如，用户点击原图横向 31.9%、纵向 48.9% 的位置，记录为：

```text
(x：31.9%，y：48.9%)
```

## 4. 发送结果

标记完成后：

- 原始图片附件保持不变；
- 不生成第二张图片；
- 不修改原始图片文件；
- 发送消息时，为该图片生成坐标说明文本。

输出格式与 Codex App 的图片标注结果一致：

```text
图像 1：
1.（x：31.9%，y：48.9%）图片显示区域
2.（x：76.2%，y：10%）图片放大比例
3.（x：46.1%，y：9.5%）图片标记
4.（x：59.6%，y：9.5%）图片比例
```

其中：

- “图像 1”表示当前消息中该图片附件的序号；
- 每一行对应图片上的一个标记；
- 行尾文本来自该标记的输入框内容。

模型接收原始图片附件和这段坐标说明文本，通过坐标定位用户在图片中标记的位置。

## 5. 验收标准

1. 图片附件可在右侧正常预览，不再进入二进制文本编辑器。
2. 点击第二张图片后，右侧预览直接显示第二张图片。
3. 用户可在图片上连续创建编号标记并输入说明。
4. 标记坐标为相对图片的百分比，缩放或切换预览比例后含义不变。
5. 发送后，原始图片不变，消息中生成“图像 N”格式的坐标说明文本。
